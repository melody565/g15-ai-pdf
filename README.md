# AI-DEMO

線上展示：<https://g15.mpa540.tw/>

本機獨立前端原型。原工作區無既有前端、AGENTS.md 或後端可沿用。新增用途見 PROJECT-REGISTRY.md。

啟動：`node server.cjs`，瀏覽 http://127.0.0.1:4173 。

固定側欄 240px（收合 64px）、工具列 56px、五個主要入口、七個資料欄與勾選欄、20 筆虛構客戶、全域搜尋、頁內搜尋、篩選、排序、選取、20/10/5 筆分頁、420px 唯讀明細抽屜。窄螢幕自動使用圖示導覽，表格有獨立捲動區。對話框支援 Escape 與原生焦點限制。

新增、匯出與帳號僅顯示明確的未接後端提示，沒有資料保存、寄信、真實登入或 PDF 處理。20 筆客戶資料均為虛構示範資料。其餘導覽為明示的功能預留頁。無外部依賴。

已以實際瀏覽器驗證：搜尋沐光得到 1 筆、5 筆分頁下一頁顯示 6–10 筆、姓名排序 ascending、本頁全選 5 筆、抽屜開關與 Escape。1440px 視窗頁面寬 1425px，390px 視窗頁面寬 375px（均含垂直捲軸差異），無整頁橫向溢出；手機表格容器寬 262px、內容寬 1050px，僅在容器內橫向捲動。

03.05 模組位於 `/modules/03.05/`，使用獨立樣式與程式，提供 F02 雙欄申請表、明細計算、前後端驗證、PostgreSQL 持久化、簽章 Demo 工作階段隔離及樂觀鎖定版本衝突提示。後端位於 `deployment/g15/app-0305/`，以獨立容器提供本模組 API，不取代既有 App。

首頁工作空間已補齊總覽、客戶管理、PDF 文件、AI 助手與系統設定；PDF 與 AI 使用明確標示的虛構內容及前端規則式互動。左側「專案申請」連結至已接 PostgreSQL 的 03.05 模組，不再顯示功能預留頁。

總覽與 PDF 文件區使用專案內的原創 AI 生成 WebP 插畫；圖片均提供文字替代資訊或作為裝飾性縮圖，不依賴外部圖片服務。
